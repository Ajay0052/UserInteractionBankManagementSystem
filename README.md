# 🏦 Bank Management System

A comprehensive **Console-Based Bank Management System** developed in **Java**, designed to simulate real-world banking operations through an interactive command-line interface. The application allows users to manage bank accounts efficiently while demonstrating the practical implementation of core and advanced Java concepts.

---

## 📌 Project Overview

The Bank Management System enables users to perform various banking operations such as account creation, deposits, withdrawals, money transfers, account searching, and account management through a simple and user-friendly console interface.

This project was developed to strengthen object-oriented programming skills and gain hands-on experience with Java collections, exception handling, file handling, and modular application design.

---

## ✨ Features

### 👤 Account Management
- Create new bank accounts
- View account details
- Search accounts by account holder name
- Search accounts using account number
- Display all registered accounts
- Delete existing accounts

### 💰 Banking Operations
- Deposit money into an account
- Withdraw money from an account
- Transfer funds between accounts
- Check account balance
- View transaction history

### 🔒 Validation & Security
- Input validation for banking operations
- Insufficient balance handling
- Duplicate account prevention
- Exception handling for invalid operations
